Sobre mim

José Douglas Farias Rodrigues

Desenvolvi este projeto para demonstrar como transformo uma necessidade de negócio em uma experiência web prática: navegação por categorias, catálogo editável e sacola responsiva.

O foco foi manter o código organizado, separar a interface das operações administrativas e deixar a integração com Supabase e Netlify configurável, sem credenciais no repositório.
